# Компьютерная графика

Лабораторные работы: локальные веб-приложения на HTML, CSS и JavaScript.

| Папка | Работа |
|---|---|
| [lab1](lab1/) | Цветовые модели CMYK, RGB, HLS и HSV |
| [lab2](lab2/) | Поэлементные операции, контрастирование и эквализация гистограмм |
| [lab3](lab3/) | Растровые алгоритмы построения отрезков и окружностей |
| [lab4](lab4/) | Отсечение отрезков и выпуклых многоугольников |

В каждой папке `index.html` содержит интерфейс приложения, `README.md` описывает реализацию и файлы, а `Отчёт_Лабораторная_N.pdf` и `.docx` содержат отчёт по работе.
