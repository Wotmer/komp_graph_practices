# Лабораторная работа 3 — растровые алгоритмы

Приложение для исследования растеризации отрезков и окружностей.

## Реализовано

- Построение отрезков пошаговым алгоритмом, ЦДА и алгоритмом Брезенхема.
- Построение окружности алгоритмом Брезенхема.
- Координатная сетка, масштабирование, пошаговое построение и таблица вычислений.
- Сравнение времени работы алгоритмов, сохранение рисунка в PNG и вычислений в CSV.

## Файлы

- `index.html` — интерфейс приложения.
- `style.css` — стили.
- `app.js` — управление, визуализация, таблица шагов и измерение времени.
- `algorithms.js` — алгоритмы растеризации.
- `Отчёт_Лабораторная_3.pdf`, `Отчёт_Лабораторная_3.docx` — отчёт.
