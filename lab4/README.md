# Лабораторная работа 4

Алгоритмы отсечения отрезков и многоугольников. Реализованы **все 21 варианты**: три алгоритма первой части и обе задачи второй части.

## Запуск

Откройте `index.html` в современном браузере. Файлы `style.css`, `algorithms.js` и `app.js` должны лежать рядом. Интернет, сервер, сборка и установка зависимостей не нужны. Предыдущие лабораторные не изменены.

## Использование

1. Выберите номер варианта. Доступные алгоритмы и задачи автоматически ограничиваются заданием. «Все алгоритмы» открывает весь набор.
2. Выберите часть работы, встроенный пример либо загрузите TXT. Можно отредактировать координаты непосредственно в поле ввода.
3. Нажмите «Выполнить отсечение», если меняли текст вручную.
4. Рассмотрите результат: синий цвет обозначает окно, оранжевый пунктир — исходную геометрию, зелёный — видимую часть.
5. Выберите отрезок и просмотрите разбор кнопками, ползунком или автоматическим воспроизведением. Жёлтый цвет показывает текущую ветвь/промежуточную фигуру или активное ребро окна. Счётчики и таблица содержат итог; остальные отрезки остаются в итоговом состоянии.
6. Колесо мыши меняет масштаб относительно указателя, перетаскивание сдвигает вид. «Вписать всё» включает фигуры, окно и начало координат. Единица по X и Y имеет одинаковый размер, Y направлена вверх.
7. Сохраните исходный TXT, итоговые координаты JSON или текущий рисунок PNG. После неприменённых изменений или ошибки ввода экспорт заблокирован.

## Алгоритмы и варианты

| Часть | Варианты | Реализация |
|---|---|---|
| 1 | 1, 4, 7, 10, 13, 16, 19 | Сазерленд–Коэн через явную прямую `y = y₀ + k(x − x₀)`; вертикальная прямая отдельно |
| 1 | 2, 5, 8, 11, 14, 17, 20 | Лианг–Барски через параметрический отрезок |
| 1 | 3, 6, 9, 12, 15, 18, 21 | Рекурсивный метод средней точки |
| 2 | Чётные | Кирус–Бек: отрезки и произвольное выпуклое окно |
| 2 | Нечётные | Сазерленд–Ходжман: выпуклый многоугольник и выпуклое окно |

Вычисления находятся в `algorithms.js`, управление и Canvas — в `app.js`. Внешних библиотек у приложения нет.

## Форматы TXT

Часть 1 точно соответствует формату задания. Пример `samples/rectangle.txt`:

```text
2
-8 0 8 0
0 -8 0 8
-5 -3 5 3
```

Первая строка — число отрезков, затем по одной строке `X1 Y1 X2 Y2`, в конце `Xmin Ymin Xmax Ymax`. Граница входит в окно.

Для части 2 формат расширен, поскольку файл задания не задаёт формат многоугольников.

**Отрезки и выпуклое окно** (`samples/convex-window.txt`):

```text
2
-8 0 8 0
0 -8 0 8
4
-5 -3
5 -3
5 3
-5 3
```

После отрезков задаются число вершин окна и координаты каждой вершины `X Y`.

**Выпуклый многоугольник и выпуклое окно** (`samples/polygon.txt`):

```text
3
-8 -2
8 -2
0 7
4
-5 -3
5 -3
5 3
-5 3
```

Сначала число вершин исходного многоугольника и его вершины, затем число вершин окна и его вершины. Повторять первую вершину в конце не нужно. Поддерживается обход в обоих направлениях; вершины должны идти последовательно по границе.

Числа разделяются пробелами или табуляцией; десятичный разделитель — точка. Допускается экспоненциальная запись, UTF-8 BOM, пустые строки и комментарии `#`. Лишние/неполные строки, NaN, Infinity, неправильные размеры окна, невыпуклые/самопересекающиеся многоугольники отклоняются. Режим выбирается перед загрузкой файла.

## Численная точность

- Граница принадлежит области видимости. Точка внутри окна и касание отображаются; касание многоугольников может дать одну или две вершины с площадью 0.
- Метод средней точки делит неоднозначные ветви до длины `10⁻⁶`, затем проецирует середину граничного интервала внутрь окна. Это приближённый алгоритм: почти касающиеся фигуры в пределах этого допуска могут отображаться как касание. Остальные реализации используют непосредственные пересечения в `Number` (IEEE 754 double).
- Для проверки выпуклости, повторов и параллельного положения в Кирусе–Беке используется допуск `10⁻⁹` в соответствующих геометрических проверках. Это не вычисления с точными рациональными числами; крайне близкие к вырождению данные ограничены точностью floating point.
- До 200 отрезков; от 3 до 64 вершин каждого входного многоугольника; модуль координат до 100 000. Загрузка до 1 МБ. Прямоугольное окно должно иметь положительную ширину и высоту.
- Таблица округляет координаты до 6 знаков. JSON сохраняет исходную точность вычислений.

## Проверки

Из каталога `lab4`:

```sh
node test.cjs
node test-ui.cjs
```

Node.js 18+, без дополнительных пакетов.

`test.cjs`: **36 243 проверки**, 3 211 случаев отсечения отрезков и 515 вызовов отсечения многоугольников. Есть независимый эталон по пересечениям рёбер, аналитические примеры, случайные данные с фиксированным seed, смена направления, идемпотентность, симметрия площади и проверка входных файлов.

`test-ui.cjs`: **105 проверок** обработчиков интерфейса в небольшой модели DOM, включая все варианты, встроенные примеры, шаги, загрузку файла и экспорт. Это не проверка реальной вёрстки браузером. Доступ к браузеру при подготовке работы был недоступен, поэтому визуальный браузерный прогон не выполнен.

Ключ `--save` сохраняет результаты в `results/test-results.json` и `results/ui-test-results.json`. Расчётные примеры — в `results/examples.json`; рисунки показывают их геометрию и не являются скриншотами интерфейса.
