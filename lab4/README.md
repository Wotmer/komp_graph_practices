# Лабораторная работа 4 — отсечение

Приложение для отсечения отрезков и выпуклых многоугольников. Поддерживаются все 21 вариант задания.

## Реализовано

- Отсечение отрезков прямоугольным окном: Сазерленд–Коэн, Лианг–Барски и метод средней точки.
- Отсечение отрезков выпуклым окном: Кирус–Бек.
- Отсечение выпуклого многоугольника: Сазерленд–Ходжман.
- Выбор варианта, координатная сетка, масштабирование и пошаговая визуализация.
- Ввод и загрузка координат из TXT, встроенные примеры, экспорт TXT, JSON и PNG.

## Файлы

- `index.html` — интерфейс приложения.
- `style.css` — стили.
- `app.js` — управление, визуализация, загрузка и экспорт данных.
- `algorithms.js` — алгоритмы отсечения и разбор входных данных.
- `samples/` — примеры входных TXT для трёх режимов.
- `results/` — расчётные примеры, рисунки и сохранённые результаты проверок.
- `test.cjs`, `test-ui.cjs` — проверки алгоритмов и обработчиков интерфейса.
- `generate_report.py` — генератор отчёта DOCX и рисунков.
- `Отчёт_Лабораторная_4.pdf`, `Отчёт_Лабораторная_4.docx` — отчёт.
