# Лабораторная работа 2 — вариант 1

Поэлементные операции и линейное контрастирование; построение и эквализация гистограмм.

## Запуск

Скачайте репозиторий и откройте `lab2/index.html` в современном браузере. Держите `app.js`, `processing.js` и `samples.js` рядом с HTML. Сборка, интернет и установка библиотек для приложения не нужны.

При необходимости запуск через локальный сервер из папки `lab2`:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Использование

1. Выберите встроенное изображение или загрузите PNG, JPEG, WebP либо другой поддерживаемый браузером формат.
2. Выберите метод. Он автоматически применяется к исходному изображению, а не к предыдущему результату.
3. Для гамма-преобразования задайте γ от 0,1 до 5; для сдвига — число от −255 до 255.
4. Сравните изображения и гистограммы RGB или HSV V на общей шкале частот.
5. Кнопка «Сохранить PNG» выгружает результат; «Сбросить» возвращает исходное изображение.

## Методы

- Негатив: `y = 255 − x`.
- Сдвиг яркости: `y = clamp(x + b)`.
- Гамма: `y = 255 · (x/255)^γ`, γ < 1 осветляет, γ > 1 затемняет.
- Линейное контрастирование: min–max по каналам RGB либо по V в HSV.
- Эквализация: нормированная накопленная гистограмма с вычитанием CDF_min; независимо по RGB либо только по V в HSV.

Значения округляются и ограничиваются диапазоном 0–255. Однотонные каналы при контрастировании и эквализации не меняются. HSV V = max(R,G,B); при изменении V каналы масштабируются на V′/V, что сохраняет H и S до квантования. На чёрном цвете тон не определён. RGB-эквализация может изменить оттенки. Дискретная эквализация не гарантирует идеально равномерной гистограммы.

## Тестовые изображения

Все 10 изображений синтетические, размер 640 × 400. Созданы специально для этой работы; чужие фотографии не использовались.

| Файл | Назначение |
|---|---|
| `samples/low-contrast.png` | Узкий диапазон V 94–151: сравнение растяжения и эквализации |
| `samples/skewed.png` | Тени и два крайних пикселя: min–max уже 0–255, эффект даёт эквализация |
| `samples/color.png` | Цветные поверхности: сравнение изменения оттенков при RGB и HSV V |
| `samples/constant.png` | Однотонное поле: проверка деления на ноль и сохранения цвета |

Дополнительные случаи:

| Файл | Эффект обработки |
|---|---|
| `samples/fog.png` | Линейное растяжение помогает различать силуэты в дымке |
| `samples/document.png` | Повышение контраста делает бледные штрихи заметнее |
| `samples/noise.png` | Растяжение и эквализация усиливают зернистость вместе со слабым сигналом |
| `samples/quantized.png` | Шесть уровней остаются шестью; полосы становятся резче |
| `samples/clipped.png` | Контраст здания растёт, но детали пересвеченного неба не восстанавливаются |
| `samples/full-range.png` | Все 256 уровней равновероятны: оба преобразования не меняют изображение |

«Хорошо» и «плохо» описывают полезность конкретного эффекта, а не корректность алгоритма. Исходники специально синтезированы с известными свойствами. Это не фотографии. Сравнения для девяти непостоянных сцен сохранены в `results/*-comparison.png`. У каждого встроенного примера есть пояснение.

`generate_samples.py` воспроизводит PNG, встроенные копии `samples.js` и сжатые RGBA-данные для тестов. Каталог всех 10 примеров — `samples/manifest.json`. Для генератора нужен Python с Pillow (`python3 -m pip install Pillow`). Приложение использует встроенные data URL, поэтому примеры не требуют сервера. Файлы `.rgba.gz` нужны только автоматическим проверкам.

## Проверки

Из папки `lab2` выполните:

```sh
node test.cjs
```

Node.js 20+; дополнительных пакетов нет. Ожидается `PASS` и 15089 проверок. В выводе также приведены диапазон, среднее, стандартное отклонение и энтропия V для 10 изображений. Эти характеристики описывают распределение, но сами по себе не доказывают улучшение качества.

В браузере проверены переключение методов, однотонное поле, неверная γ, сброс, загрузка PNG и экспорт. Функции обработки находятся в `processing.js`, интерфейс — в `index.html` и `app.js`.

## Ограничения

Прозрачность загруженных файлов сводится на белый фон. Файлы крупнее 30 МБ отклоняются. Изображения больше 2 млн пикселей уменьшаются; итоговый PNG имеет обработанный размер. Вычисления выполняются над 8-битными каналами без линеаризации sRGB и управления ICC-профилями. Эквализация может усиливать шум, линейное растяжение чувствительно к крайним пикселям.
