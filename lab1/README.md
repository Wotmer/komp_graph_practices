# Лабораторная работа 1 — цветовые модели

Приложение для преобразования и сравнения представлений цвета.

## Реализовано

- Преобразования CMYK ↔ RGB ↔ HLS и дополнительный режим CMYK ↔ RGB ↔ HSV.
- Ввод компонентов числами и ползунками, выбор цвета из палитры и ввод HEX.
- Синхронное обновление моделей и предпросмотр цвета.

## Файлы

- `index.html` — интерфейс, стили и обработчики событий.
- `color.js` — преобразования цветовых моделей.
- `test.cjs` — проверки преобразований.
- `interface.png` — снимок интерфейса.
- `Отчёт_Лабораторная_1.pdf`, `Отчёт_Лабораторная_1.docx` — отчёт.
