ЛАБОРАТОРНАЯ РАБОТА 1. ЦВЕТОВЫЕ МОДЕЛИ

ЗАПУСК
Скачайте репозиторий. Откройте lab1/index.html в браузере.
Файл color.js должен находиться в одной папке с index.html.
Интернет, сборка, сервер и дополнительные библиотеки не нужны.

ВАРИАНТ
Чётный: CMYK — RGB — HSV (дополнительный режим).
Нечётный: CMYK — RGB — HLS (выбран по умолчанию).
Выберите нужный набор в списке «Вариант».

ВОЗМОЖНОСТИ
1. Числовой ввод любой компоненты в каждой модели.
2. Плавное изменение ползунками.
3. Палитра браузера в каждой панели и общие готовые цвета.
4. Автоматический пересчёт остальных моделей.
5. Ввод HEX с символом # или без него, например #4275DF.
6. Проверка допустимых диапазонов и кнопка сброса.

ФАЙЛЫ
index.html — интерфейс, стили и обработчики событий.
color.js — функции преобразования цветовых моделей.
test.cjs — воспроизводимые проверки формул.

ТЕСТИРОВАНИЕ
Если установлен Node.js, из папки lab1 выполните: node test.cjs
Ожидаемый результат: PASS; 90123 проверки, 30000 обратных
преобразований для 10000 псевдослучайных цветов.
Node.js нужен только для тестов, для приложения он не требуется.

ПРИМЕЧАНИЯ
CMYK использует учебные формулы без ICC-профиля печати.
RGB хранится с дробной точностью; HEX и стандартная палитра
округляются до 8 бит на канал. Поля показывают до трёх знаков
после запятой, шаг ползунков 0.01.
При переходе из RGB в ахроматический цвет H условно равен 0.
HLS и HSL — одна модель с разным порядком компонент.

ОТЧЁТ
Отчёт оформлен для нечётного варианта CMYK — RGB — HLS.
Формулы отчёта относятся к CMYK, RGB и HLS.
